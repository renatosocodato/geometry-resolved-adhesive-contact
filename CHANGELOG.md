# Changelog

## 0.2.0

- Adds a Python interface for user-defined signed gaps, section metrics and plane-normal traction laws.
- Supports caller-specified breakpoints, including multiple crossings of the same branch threshold.
- Adds an independently integrated wavy-wall example and tests for the custom interface.
- Adds bracketed transition location for known monotone partitions and a narrow-contact benchmark that accounts for gap-search costs.

## 0.1.0

- First installable Python release, with an API and CLI for circular and monotone-gap noncircular extruded walls.
- Includes the companion manuscript's synthetic configurations, numerical reference tables, benchmark and diagnostic scripts, and R figure sources and artwork.
- Adds an isolated reproduction command and checks of the released API against the archived benchmarks.
